Deployment manual
--------------------


1. App.Config - Fix paths in <nlog> section
2. App.Config - add your connection string in <connectionStrings>, give it your name, ex. EurekaStrokeEntities
3. App.Config - fix UploaderPath path in <appSettings>
4. App.Config - Specify the name of your connection string, ex. EurekaStrokeEntities in section <applicationSettings>    <Core.Properties.Settings>
